Tentang
TG

TeGe Flipbook Studio

Versi 1.2

Mesin pembuat flipbook HTML interaktif berbasis browser. Ubah kumpulan gambar atau PDF menjadi buku digital dengan animasi lengkungan kertas dan suara membalik halaman, lalu ekspor menjadi satu HTML mandiri atau paket ZIP untuk publikasi.

Teknologi

HTML5Canvas 2D page curlCSS3 & JavaScriptCanvas APIPDF.js (impor PDF)HTML5 AudioZIP Builder mandiri

Pembaca hasil ekspor menggunakan kode mandiri tanpa CDN. Impor PDF pada studio menggunakan PDF.js yang dimuat dari CDN saat diperlukan.

Keamanan data

  • ✓Gambar dan PDF diolah secara lokal di browser. Tidak ada fitur untuk mengunggah dokumen ke server.
  • ✓Tanpa akun, iklan, atau pelacak yang ditambahkan ke mesin.
  • ✓Flipbook hasil ekspor HTML atau ZIP dapat dibaca offline; studio memerlukan internet hanya ketika pertama kali memuat PDF.js untuk impor PDF.
  • ✓File hasil ekspor disimpan melalui fitur unduh browser. Tidak ada penyimpanan proyek permanen oleh mesin.
